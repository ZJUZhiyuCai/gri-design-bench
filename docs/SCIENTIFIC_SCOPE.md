# GRI Design Bench 的科学问题与证据

**这个项目研究模拟中的葡萄糖响应释药能否改变血糖控制，以及这种变化来自给药量还是释放时序。** 真实研发中，研究者需要在不确定的进餐条件下判断一种响应机制值不值得做下一轮材料实验。计算研究可以比较同一虚拟患者在不同释放历史下的结果，并把验证条件写成他人可以复算的任务。聚合排名无法提供这种归因。

研究场景来自葡萄糖响应胰岛素的计算设计，以及聚合物膜包裹胰岛素晶体的实验。项目使用一个葡萄糖单输入、有限储库的释药模型与 simglucose 生理模型。释药形状的部分范围来自体外数据，剂量、载量和部分参数边界由 benchmark 构造。结论限于这里的模型、条件与预先指定的设计。当前生理方程未纳入 UVA/Padova 后续版本的低血糖反调节机制，真实材料实现、体内迁移和临床安全仍需独立证据。 [GRI 计算设计](https://doi.org/10.1002/adhm.201700601) · [Xu 等的制剂研究](https://doi.org/10.1038/s41565-025-01860-0) · [参数来源](BOUND_PROVENANCE.md) · [simglucose](https://github.com/jxx123/simglucose) · [UVA/Padova 后续模型](https://pubmed.ncbi.nlm.nih.gov/24876534/)

## 这次升级回答的问题

取六组已公开的虚拟患者，以及每组一份历史上经过高预算搜索选定的响应设计。使用四个新进餐种子和三类进餐变体。对同一患者与进餐记录，保留第一天的原响应释放历史，随后比较原响应、逐日匀速释放、逐日循环平移 12 小时的释放。后两个条件每天实际给药总量均与原响应相同，且以开环方式重放。这个对照把每天给药量作为固定条件，检验日内时序在当前模型中的作用。

216 个配对情景中，原响应相对匀速释放的平均 TIR 高 **5.82 个百分点**，TBR70 低 **3.74 个百分点**。相对循环平移的差值分别为 **+10.08** 和 **−6.17**。以匀速为参照，六组的平均 TIR 差值从 +0.55 到 +12.30 个百分点，部分单情景的 TIR 下降。逐日用量匹配的是已实现的释放量。匀速和平移对照都用到整日原响应轨迹，因此属于事后机制对照。实时可用的固定释放策略仍是另一个需要比较的问题。 [实验结果、复现和局限](../results/timing-study-2026-11-13/README.md)

旧版探索研究发现，固定验证改善了有限面板的通过次数，逐级淘汰未改变最终设计。高预算参考在同一研究的评测面板表现明显更好。这个结果支持继续区分候选生成、验证选择、释药机制三者的贡献。旧版搜索与验证实验仍作为历史证据使用。 [搜索与验证预筛](../results/search-validation-prescreen-2026-11-13/CONCLUSION.md)

## 下一版怎样增加科学价值

已增加一个候选筛选实验，用于检验新证据能否改变推进或暂缓的决定。模型能力、研发价值和独立复核的关系另见 [研究闭环](RESEARCH_LOOP.md)。

1. **检验结论的范围。** 固定材料设计和评估规则，增加响应幅度、泄漏和延迟的少量有依据扰动，逐个记录同剂量的时序效应与低血糖权衡。评测前确定新的进餐面板，按患者组报告差异，避免把重复情景当独立患者。将结论写成哪些条件下效应出现或消失。
2. **引入真实研究取舍。** 让参与者根据公开的体外释放证据选一项有成本的追加测量，或在两个可解释的释放模型之间作可证伪的预测。首先用离线控制检查固定测量组合能获得多少收益。任务只有在追加证据改变模型判断或下游设计结论时才适合作为决策评测。机制解释可读，关键预测和结果应可程序化验证。
3. **把论文主张系于可重复的发现。** 一条路线是报告模型内时序效应的条件和失效机制，需要跨设定复核。另一条路线是研究哪些可核验任务真正要求科学判断，需要共享候选与信息、合理的非模型对照和领域审查。后续少量 Agent 试验可用于解释失败来自哪一步，并校准任务难度。

当前主线以第 1 项为下一阶段。第 2 项的实验价值和验收仍需先做无模型检查。 [Harbor 原型与运行方法](../harbor/release-timing-attribution/README.md) · [四个控制的实际记录](../results/timing-study-2026-11-13/harbor-verification.json)
