# Shared responsive formulation for dev-05

The submitted formulation uses theta_a=0.00026, relative_leak=1.5, EC50=90 mg/dL, Hill exponent=24, filter tau=0.05 minutes, and reservoir load theta_L=4. All coefficients are shared across adolescent#004, #005, and #006 and lie within the instance bounds. Only native TDI scales amplitude and reservoir capacity.

The minimum permitted leak maximizes the available relative modulation. The steep response reduces release as interstitial glucose falls through 90 mg/dL. The short filter avoids additional response delay; physiological insulin delays still remain. The maximum possible release is 0.00065 times TDI U/min, and the leak floor is 0.00039 times TDI U/min. The four-TDI reservoir cannot exhaust during three days because even the maximum release would consume only 2.808 TDI. No meal boluses, individual fits, or external controller are used.

Search first screened amplitudes and response shapes on the supplied seed, then compared leading candidates across six meal seeds and all three variants. Higher amplitudes were rejected despite increased TIR because they caused excessive hypoglycemia or eroded the safety margin. Screening used the public RK4 simulator with one substep per minute. Final validation used four substeps per minute, the API default.

The selected formulation was validated on 135 trajectories: all three patients, all three variants, and 15 seeds (6111005, 6111021, 6111137, 6111251, 6111409, 6111613, and 7320100 through 7320108). Mean post-warmup TIR was 87.3256%; maximum trajectory TBR70 and TBR54 were both 0%; full-horizon minimum glucose was 71.6970 mg/dL. The first day was omitted from TIR/TBR but retained in the minimum. Nine of these seeds were additional checks after the six-seed candidate comparison. Results are stored in results.jsonl and selected.json.

These finite scenario checks do not guarantee the strict heldout safety criterion, and the independent verifier uses native dopri5. The native dopri5 spot check on the lowest-glucose validation trajectory (adolescent#004, seed 7320101, large_dinner) also had zero TBR70/TBR54 and minimum glucose 71.6970 mg/dL; its TIR was 76.1458%. The native minimum agreed with RK4 to within 0.000001 mg/dL. This spot check covers one trajectory, not the entire validation set. See native_check.json. This is a simulation benchmark design, not a clinical recommendation.

To reproduce the full staged search, run `OPENBLAS_NUM_THREADS=1 python /work/output/search.py all` with the public benchmark installed. Individual stages can be run by name: screen, refine, shape, robust, polish, validate, native. Full reproduction needs its own compute allowance. The native stage checks the final-validation trajectory with the lowest full-horizon glucose. Design checkpoints use atomic replacement. Search records retain both rejected and selected candidates for audit.
