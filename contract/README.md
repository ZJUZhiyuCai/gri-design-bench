# Frozen task contract

Material subranges are synthetic benchmark constraints inside the previously fitted shape envelope. This is a new benchmark, not a revision of either GRI prescreen. Full-horizon low glucose is checked, including warmup.

Protocol must be committed before benchmark search. Sealed cases are committed by salted hashes and remain outside public git. Any implementation repair must preserve this contract and all original failed attempts.
