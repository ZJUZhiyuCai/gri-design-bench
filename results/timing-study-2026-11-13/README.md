# 同日等剂量的释药时序对照

2026-11-13。对六组公开开发患者的固定响应设计，改变日内释放时序会改变模拟血糖结局。相对逐日匀速对照，原响应的平均 TIR 增加 5.82 个百分点，TBR70 下降 3.74 个百分点。这个比较的每日总剂量匹配到数值精度。

| 条件 | 平均 TIR (%) | 平均 TBR70 (%) | 平均 TBR54 (%) | 触发任一低血糖门槛 |
|---|---:|---:|---:|---:|
| 原响应时序 | 68.06 | 0.02 | 0.00 | 0 / 216 |
| 每日匀速 | 62.23 | 3.76 | 0.00 | 72 / 216 |
| 每日循环平移 12 小时 | 57.97 | 6.18 | 0.59 | 101 / 216 |

TIR 和 TBR 是第 2、3 天的三分钟血浆端点指标。模拟门槛沿用 v0.2 的 TBR70 大于 4%、TBR54 大于 1% 或全程分钟采样最低值小于 40 mg/dL，表中计任一违规的情景。三个条件的全情景最低值依次为 69.14、57.84 和 42.87 mg/dL。上述数值描述固定模型中的采样情景。

相对匀速对照，原响应在 162/216 个情景提高 TIR，在其余情景持平或降低。dev-04 中原响应 TIR 提升最大，其平均最低血糖较匀速低 10.66 mg/dL，两种条件的 TBR70 均为零。逐组呈现结果有助于识别平均 TIR 掩盖的权衡。普通、漏午餐和大晚餐的分层结果保存在摘要中。 [逐情景数据](outcomes.json) · [分组摘要](summary.json)

## 方法

- 六个开发组、18 名已见虚拟患者，每组历史高预算响应设计一份。每组四个新种子，每个患者和种子组合包含普通、漏午餐和大晚餐三类进餐。216 个情景共享 18 个患者身份，报告采用配对描述。
- 用原生 dopri5 生成三天响应历史。每个情景的第一天释放相同，第二和第三天各自用相同的日总量做匀速化或循环平移。用原样释放历史开环重放时，216 个对照与原响应的每分钟血浆轨迹最大差为 0。改动时序后的最大每日剂量差为 (2.13\times10^{-14}) U。
- 历史设计先于本轮已选定，运行计划和代码摘要在首次仿真前本地记录。评估范围是已见生理参数与新进餐条件。两个开环对照使用原响应整天的实际给药量和时序，故适用于事后干预比较。这里未估计实时策略的效果或跨人群、跨模型的迁移性。

在仓库根目录按[主 README](../../README.zh-CN.md#复现)安装项目，再指定一个新的输出目录运行。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 NUMBA_NUM_THREADS=1 \
  .venv/bin/python -I scripts/run_timing_study.py --output private/timing-reproduction
```
